# Vision

`claude-home-assistant` is the nolte portfolio's Claude Code plugin for Home
Assistant development. It bundles skills and agents that author Home Assistant
artefacts — custom integrations, Lovelace cards, blueprints and automations, and
ESPHome / add-on work — against Home Assistant Core and HACS conventions. It owns
the Home-Assistant-development skill and agent set in the portfolio, distinct from
claude-shared's portfolio-wide skills.

## Outcomes

- **O-1** — the plugin author, dogfooding in this repository, builds Home
  Assistant integrations, cards, blueprints, automations, and ESPHome work with
  consistent, spec-grounded skills and agents. _(audience: Plugin-Autor beim Dogfooding in diesem Repo (nolte))_
- **O-2** — later public users in the Home Assistant integration and card author
  community adopt the same skills and agents through the Claude Code plugin
  marketplace. _(audience: Spätere öffentliche Nutzer (HA-Custom-Integration- und Card-Autoren-Community))_
